# Shamanic Mounts 0.1.13 - Only Followers

The Mount Flute calls the mounts following you, and leaves the rest where you put them.

- **Follow only.** The Mount Flute now calls only mounts set to Follow. A mount left on Stay or Wander stays put, and the flute no longer switches the mounts it calls to Follow. A mount away at a Trading Post still comes home on the flute if it is on Follow.
- **Nothing following?** The flute says so: set a mount to Follow to call it.
- **Lighter on the world.** A parked mount in a far-off chunk is skipped without loading that chunk. A mount saved before this version is checked once, the next time its chunk loads.

Minecraft 1.21.1, NeoForge 21.1.249, Java 21. Client and server.
