# Shamanic Mounts 0.1.15 - Said Once

A fix and a polish pass. Nothing new to tame; saves load as they are.

- **Hints print once.** With Tribal Power, Ninjacat Skies Core or Chocobos Reborn installed, every hint line showed once per mod, four times over. Each mod now speaks only for its own items.
- **No ghost rider.** A teleport or dimension change while holding sneak on a shade, blink or coil mount used to leave the mount believing its rider was still aboard: it never followed and the seat stayed taken. It now lets go.
- **The trial saddle comes back.** If the world closes in the middle of a rein trial, the mount hands back the saddle it was wearing when it next loads, as a failed try would, instead of keeping it as a wild mount or losing it.
- **Bags stay honest.** Items can only be placed in the saddle-bag slots while bags are strapped on; the server now refuses it too, not just the screen.
- **Tidy-ups.** Released or dead mounts leave the herd's last-seen ledger; the mount screen allocates less each frame.

Minecraft 1.21.1, NeoForge 21.1.249, Java 21. Client and server.
