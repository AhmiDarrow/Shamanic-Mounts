# Shamanic Mounts 0.1.12 - Flute Songs

The Mount Flute plays a real tune.

- **Four phrases, in turn.** The Mount Flute plays a short wooden-flute phrase every time you blow it, whether or not a mount hears it. It has four phrases and plays them in order, so two calls in a row never sound the same. Before, it played a single note-block note, and only when a mount answered.
- **No droning.** If nothing answers, the flute rests for two seconds, one phrase, before you can play it again, so holding the button no longer repeats it. When mounts answer, the usual three-second wait still applies.
- **Subtitles** show "Mount Flute plays".

The phrases are original recordings made for this mod.

Minecraft 1.21.1, NeoForge 21.1.249, Java 21. Client and server.
