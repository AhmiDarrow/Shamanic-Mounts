# Shamanic Mounts 0.1.1 - Lean Herd

A smaller jar that carries only what the game runs.

- **Lean jar.** The development test driver, retired renderer code, unused constants, and an unused texture are gone from the release. Nothing players see or do changes.
- **No hidden timing.** Render statistics are counted only in development runs, so a player's game never times itself.

Everything from 0.1.0 is unchanged: ten spirit mounts in their own biomes, genes for every part, the herd book, and the chimera.

Minecraft 1.21.1, NeoForge 21.1.249, Java 21. Client and server.
