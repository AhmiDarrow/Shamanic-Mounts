# Shamanic Mounts 0.1.10 - One Herd

Your tame mounts no longer turn on each other.

- **Tame mounts are one herd.** The Bear's maul, the Elk's ram, and the Serpent's coil hit everything in front of them except other tame mounts. Before, a maul that caught a tame mount standing nearby started a fight between the two that only ended when one died.
- **Tames never fight each other at all.** A tame mount never takes another tame mount as a target, and a hit from one tame mount on another does nothing, so nothing sets them off. Wild mounts are still fair game both ways, and a tame still defends you.

Minecraft 1.21.1, NeoForge 21.1.249, Java 21. Client and server.
