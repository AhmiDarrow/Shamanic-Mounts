# Shamanic Mounts 0.1.5 - Wild Herds Stay

Wild mounts no longer vanish before you can reach them.

- **Wild herds stay where they were born.** Untamed mounts despawned like monsters as soon as no player stood near. Most mounts are born with new land, out at the edge of sight, so they were gone before anyone arrived, and the animals that never leave kept the area too full for more to be born later. Wild mounts now stay put like any other animal, so the land you explore keeps its herds. Tamed mounts and foals were never affected.

Minecraft 1.21.1, NeoForge 21.1.249, Java 21. Client and server.
